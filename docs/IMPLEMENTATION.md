# Atypoi 개발 빌드 구현과 검증 상태

버전: 0.1.6 · 대상: Windows x64

설치 프로그램을 포함한 개발 빌드이며, 공개 출시 완료 기준 전체를 충족한 정식 버전은 아니다. 실제 입력 검증 범위와 재현 방법은 [INPUT-VERIFICATION.md](INPUT-VERIFICATION.md)에 기록한다.

## 생성된 실행 파일

| 파일 | 용도 |
| --- | --- |
| `dist/Atypoi.Setup.exe` | 설치·업데이트·제거 UI, 관리자 작업 분리, 입력기 등록, 사용자별 자동 시작과 바로가기 |
| `dist/Atypoi.exe` | 트레이, 설정, 앱별 정책, 입력 테스트, 업데이트 확인 |
| `dist/Atypoi.IME.dll` | 한영 판단 엔진을 포함한 TSF 입력기 |
| `build/Atypoi.Tests.exe` | 단위·속성·Windows 통합 검사 |

설치 없이 확인하려면 `Atypoi.exe --demo`를 실행한다. 설치 후 `Atypoi 입력기 켜기` 버튼으로 현재 세션에서 입력기를 활성화한다. 메모장(스토어 버전)과 Chrome의 일반 설치 경로는 기본 지원하고, 다른 앱은 명시적으로 허용한다. 개발 빌드는 게시자 서명이 없다.

## 구현 범위

| PRD 기능 | 구현 내용 | 검증 상태 |
| --- | --- | --- |
| FR-01 판단·조합 | 두벌식 전 음절, 영어·한국어 모델, 문맥 점수, 고정 모드, 원문 보존 | 엔진 회귀·전 음절 검사 통과. 독립 정확도 목표는 미측정 |
| FR-02 키 처리 | 조합·확정·삭제, Space·Enter, 단축키 전달, 포커스 분리 | Windows TSF 컨텍스트 통합 검사 통과 |
| FR-03 후보 수정 | 조합 중 영문·혼합·한글 순환, 선택 고정, 단축키 변경·해제 | 엔진 및 TSF 통합 검사 통과 |
| FR-04 조사 | 제한된 조사 목록과 영어 사전·약어 결합 | 예시 및 회귀 검사 통과 |
| FR-05 트레이 | 상태 표시, 단일 인스턴스, 설정 닫기 후 유지, Explorer 아이콘 재등록 | 실제 UI 프로세스 검사 통과 |
| FR-06 일시정지·종료 | 명시적 종료와 heartbeat 만료 시 입력 중지 | 정책·TSF·UI 검사 통과 |
| FR-07 자동 시작 | 설치 옵션, 사용자 Run 항목, OS 비활성화 존중 | 코드 구현. 실제 로그인 주기 시험은 미실행 |
| FR-08 보호·앱 정책 | 경로별 정책, 읽기 전용·암호·불명확 컨텍스트 제외, 구조 토큰 보호 | 네이티브 암호·읽기 전용 컨트롤 및 정책 검사 통과 |
| FR-09 설정·미리보기 | 설정 저장·손상 값 보존, 샘플 판단, 로컬 처리 | 화면 검증 및 미리보기 검사 통과 |
| 설치·제거 | 버전별 설치, 등록 실패 복구, 사용자 프로필 활성화, 사용 중 파일 제거 예약 | 실제 업그레이드 설치와 OS의 DLL 로딩 확인. 제거·재부팅 시험은 미실행 |
| 업데이트 | 공식 GitHub 최신 릴리스, 시작 후·24시간 간격 확인, 자동 다운로드·SHA256, 설치 승인 | 버전·URL·해시·서명 정책 회귀 검사. 서명된 설치본은 같은 게시자만 허용 |
| FR-10 P1 | 확정 후 재변환·개인화 학습 | 후속 범위로 미구현 |

일반·앱별 설정, 별도 입력 테스트 창과 설치 UI로 구성한다. 별도 Electron/.NET 런타임 없이 실행하는 네이티브 Windows UI다. 개인정보 안내·버전·GitHub 링크를 창에서 확인할 수 있다.

## 수행한 검사

- 총 **23,899개 assertion, 실패 0건**. 수정 키의 독립 keydown, 쌍시옷·겹받침, Shift를 누른 채 이어 입력, 조합 중 초성과 Backspace, 488개 과거형 조합, 입력기 모듈 버전 불일치 검사 포함.
- 두벌식으로 조합 가능한 한글 **11,172개 음절** 전체 결과 확인.
- 무작위 키열 2,000개에 대한 조합 범위 순서·문자 보존·UTF-8 왕복 검사.
- 자모·음절 삭제, 후보 고정과 원문 복구, 입력 버퍼 한도 검사.
- 실제 DLL 로딩, COM 객체 수명·해제, 조합 밑줄 속성 검사.
- 실제 Windows TSF 문서·텍스트 범위·편집 세션에서 한영 조합, 혼합 조사, Enter, 후보 전환, 입력란 전환, Ctrl+Z 전달, 읽기 전용·암호 필드, 부분 편집 실패에 따른 중복 방지 검사.
- 트레이 종료·heartbeat 만료와 앱별 정책 검사.
- 실제 GUI 실행에서 미리보기, 중복 실행 방지, 설정 창 닫기 후 상주, 종료 명령, 트레이 재등록 검사. 자동 시작 레지스트리가 바뀌지 않았음을 확인.
- 엔진 판단 시간은 빌드마다 테스트 출력으로 측정한다. 소규모 고정 샘플의 엔진 내부 측정이며 실제 앱 전체 입력 지연이나 정확도 측정은 아니다.

TSF 통합 시험에서는 시스템 등록을 요구하는 키 이벤트 구독만 테스트용 어댑터로 대체한다. 제품과 다른 공유 메모리 이름을 사용하는 테스트 전용 DLL로 실행한다. 별도의 데스크톱 시험은 설치된 입력기에 실제 Windows 키 이벤트를 전달한다. 두 종류의 검사 결과를 구분한다.

## 공개 출시 전 남은 검증

1. 게시자 인증서 확보 및 입력기·앱·설치 프로그램 서명. 현재 설치 파일은 서명 전 개발 패키지다.
2. 별도 Windows 테스트 계정 또는 VM에서 설치, 입력기 선택, 재로그인, 업그레이드, 실패 복구, 제거와 재부팅 후 정리 시험.
3. Edge, Word, 대상 메신저와 다양한 실제 웹 편집기의 입력기 호환성 시험. 메모장·Chrome 로컬 테스트 입력란의 결과를 모든 앱·웹사이트의 지원으로 일반화하지 않는다.
4. 커스텀 입력란의 InputScope, 관리자 앱, 앱 컨테이너, 선택 영역·Undo·붙여넣기 호환성 시험. 보안 여부를 확인하지 못하면 변환을 중지한다.
5. 독립 평가 데이터에 대한 PRD 정확도·영어 오변환·한국어 재현율 측정과 튜닝. macOS 원본의 수치를 Windows 성능으로 사용하지 않았다.
6. 8시간 지속 입력, 다중 모니터·고대비·100/150/200% DPI, 실사용 CPU·메모리 측정.
7. GitHub 공개 릴리스는 `update.txt`와 설치 파일을 함께 게시한다. 서명 도입·인증서 교체 정책은 별도 필요하다.

## 재현 명령

```powershell
powershell -ExecutionPolicy Bypass -File scripts/bootstrap.ps1
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -ExecutionPolicy Bypass -File scripts/package.ps1
powershell -ExecutionPolicy Bypass -File scripts/smoke-ui.ps1
```

빌드 전 실행 중인 Atypoi를 종료해야 바이너리를 교체할 수 있다. 빌드 도구 버전과 다운로드 체크섬은 bootstrap 스크립트에 고정되어 있다. 배포 파일 및 모델 해시는 `dist/SHA256.json`, `dist/ModelHashes.json`에 기록된다.
