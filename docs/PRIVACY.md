# 개인정보와 공개 소스

## 프로그램이 처리하는 정보

입력 판단은 로컬 사전과 통계 모델로 실행합니다. 제품은 입력 내용을 네트워크·클립보드·디스크 로그에 기록하지 않습니다. 현재 조합 중인 키열과 짧은 언어 문맥은 메모리에 있으며 확정·포커스 변경·종료 시 해당 조합 상태를 정리합니다.

사용자 설정은 `HKCU\Software\Atypoi`에 저장합니다. 앱별 허용 규칙에는 실행 파일 경로가 들어가며, 이는 해당 PC에서 앱을 식별하는 데 사용합니다. 자동 시작 설정과 사용자별 공유 메모리를 사용하지만 다른 계정의 설정을 수집하지 않습니다.

업데이트 후 재시작이 필요한지 확인하기 위해 현재 앱의 모듈 목록에서 Atypoi 입력기 경로를 설치 경로와 비교합니다. 입력 내용이나 앱 문서를 읽는 기능이 아니며, 이 경로를 외부로 보내거나 제품 로그에 저장하지 않습니다.

비밀번호·이메일·URL·숫자·읽기 전용 영역과 안전 여부를 확인할 수 없는 입력란은 변환을 통과시킵니다. 사용자 입력 내용을 모으는 학습·분석·광고·원격 진단 기능은 없습니다.

## 네트워크 동작

0.1.6부터 실행 10초 후와 실행 중 24시간마다 공식 GitHub Releases의 `update.txt`를 확인합니다. 새 버전이 있으면 설치 파일을 다운로드하고 SHA256을 검사한 뒤 알립니다. 설치는 사용자가 승인해야 진행합니다. 트레이 메뉴의 **자동 업데이트 확인**을 끄면 주기적인 요청을 중단하며, **업데이트** 버튼으로 수동 확인할 수 있습니다. `--demo`에서는 자동 확인하지 않습니다.

요청 대상은 `github.com/ssrihappy/atypoi/releases/latest/download/update.txt`와 해당 버전의 설치 파일이며, GitHub가 다운로드용 호스트로 연결할 수 있습니다. GitHub에는 통상적인 접속 정보(IP·User-Agent)가 전달됩니다. 키 입력·문서·앱 목록·개인 설정은 보내지 않습니다. 다운로드 파일은 사용자 임시 폴더에 저장하며 앱 종료 시 정리를 시도합니다.

GitHub 링크를 누르면 기본 브라우저로 프로젝트 저장소를 엽니다. 이때 입력 중인 내용을 URL에 붙이지 않습니다.

## 공개 자료의 범위

공개 소스는 프로그램·테스트·재현 스크립트·문서·브랜드와 라이선스 파일만 포함합니다. 로컬 도구체인, 빌드 캐시, 브라우저 프로필, 실행 기록, 검사 결과, 인증서·키·환경 파일과 Git 이력은 공개용 내보내기에서 제외합니다.

스크린샷과 GIF는 가상의 고정 문장과 전용 테스트 창으로 제작합니다. 전체 데스크톱과 사용자의 실제 문서는 캡처하지 않습니다. 문서에는 개인 PC의 프로세스 ID·설치 해시·개발 중 대화나 개인 테스트 경과를 기록하지 않습니다.

공개 내보내기 전에 `scripts/audit-publication.ps1`로 개인 프로필 경로와 일반적인 비밀키 형식 등을 검사합니다. 빌드에는 소스 경로를 상대 경로로 매핑하는 옵션을 사용합니다. 이 패턴 검사는 사람의 검토를 보조하며 모든 종류의 민감정보를 탐지한다고 보장하지 않습니다.

외부 코드·데이터·도구체인의 저작권자·출처·라이선스 표기는 유지합니다. GitHub 저장소 주소와 `ssrihappy`는 프로젝트가 지정한 공개 식별자입니다.
