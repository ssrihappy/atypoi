# Atypoi 0.1.7

Windows x64 · 카카오톡과 IMM 입력 호환성 개선

- 카카오톡 등 Qt 입력란에서 영문 키가 그대로 남거나 키마다 조합이 확정되는 문제를 수정했습니다.
- 단어 전체 조합이 유지되도록 Windows 입력 프로필을 변경했습니다. 입력기 목록에서는 **영어(미국)의 Atypoi**로 표시되며 한글·영어 자동 판단은 동일합니다.
- 공백·문장부호 누락을 수정하고 Shift 쌍시옷, 겹받침, 백스페이스 회귀 검사를 보강했습니다.
- 접근성 포커스·텍스트 역할·보호 상태를 확인해 Qt 일반 입력란을 지원합니다. 비밀번호·읽기 전용 입력란은 제외하며, 제품은 접근성 API로 입력 내용이나 대화 내용을 읽지 않습니다.
- 업데이트 후 이전 DLL을 사용하는 앱의 재시작 안내를 개선했습니다.

업데이트 후 **Atypoi 입력기 켜기**를 한 번 누르세요. 입력하던 앱은 작업을 저장한 뒤 완전히 종료하고 다시 실행해야 새 입력기 DLL이 적용됩니다. 카카오톡은 창 닫기만으로 종료되지 않을 수 있으므로 트레이 메뉴의 **종료**를 사용하세요. 앱별 허용 규칙에는 현재 카카오톡 실행 파일을 등록해야 합니다.

검증: 자동 검사 23,978건, 실제 Windows TSF→IMM 키 입력 검사 10건, 설치본의 자체 입력 창에서 요청한 혼합 문장 일치. 수정 개발 설치본의 카카오톡 정상 동작은 사용자가 확인했습니다. 모든 앱·입력란의 호환성을 보장하는 결과는 아닙니다. [검증 범위](INPUT-VERIFICATION.md)

0.1.6의 GitHub 자동 업데이트 경로를 유지합니다. 앱은 시작 10초 후와 실행 중 24시간마다 최신 릴리스를 확인하고 다운로드하며, 설치는 사용자가 승인한 뒤 진행합니다. 설정의 **업데이트** 버튼으로 즉시 확인할 수 있습니다.
